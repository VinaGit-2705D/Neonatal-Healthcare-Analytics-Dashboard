## Neonatal Healthcare Analytics Dashboard

 ## Project Overview

The Neonatal Healthcare Analytics Dashboard is an interactive Power BI project designed to analyze neonatal growth, health indicators, vital signs, feeding patterns, and health risk levels.

The project transforms cleaned neonatal healthcare data into meaningful visual insights using MySQL, Power BI, and DAX.

## Project Objective

The main objective of this project is to analyze neonatal health data and identify important growth patterns, abnormal health indicators, and risk factors that can support effective monitoring and data-driven decision-making.

## Tools & Technologies

MySQL – Data cleaning, transformation, validation, and analysis

Power BI – Data modeling, dashboard development, and visualization

DAX – Measures, KPIs, risk calculations, and analytical metrics

## Dataset

The cleaned dataset contains neonatal monitoring information including:

Baby ID

Gestational age

Birth weight

Weight

Temperature

Heart rate

Oxygen saturation

Feeding type

Feeding frequency

Urine output

Stool count

Jaundice level

Apgar score

Reflex status

Risk level

## Dashboard Pages
1. Executive Dashboard

Provides an overall summary of neonatal health using key performance indicators and visualizations.

2. Growth Analysis

Analyzes birth weight, gestational age, and weight-related patterns to understand neonatal growth.

3. Clinical Assessment & Risk Analysis

Focuses on vital signs, abnormal health indicators, and risk levels to identify newborns requiring closer monitoring.
